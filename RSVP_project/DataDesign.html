Course Project — Week 3

RSVP App Data Design

App RSVPProject (.NET MAUI) Storage SQLite, on-device Tables 3 — Users, Events, Rsvps

Local storage for the RSVP app, driven directly by this week's requirements: create an account, log in against stored credentials, add and list events, and RSVP with details prefilled for a signed-in user.

01

Entity relationships

Two foreign keys — Events.HostUserId and Rsvps.UserId — are nullable on purpose: a guest can host an event or RSVP without ever creating an account.

03

Relationships

Users 1 —⟶ * Events

hosts. Events.HostUserId → Users.Id. Nullable so a guest can create an event with no account.

Users 1 —⟶ * Rsvps

makes. Rsvps.UserId → Users.Id. Nullable for the same reason — a guest can RSVP without signing up.

Events 1 —⟶ * Rsvps

receives. Rsvps.EventId → Events.Id. Required — every RSVP belongs to exactly one event.
